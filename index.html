第 1 周 · 9月1日 - 9月7日 · 视频第一、二讲

环境、器件与电学入门

目标是把“能看懂、能安装、能跑起来”这三件事先做完。

优先级最高：环境先行

本周任务

  • 熟悉电脑使用，完成嘉立创 EDA、Multisim 等必要软件安装。
  • 回到高中电学：电阻、电容、电感、三极管，先知道它们在现实里是什么。
  • 理解 PCB 的作用、结构和生产工艺，不只停留在“能画板”。
  • 初步学习 C 语言，配置开发环境，独立跑通第一个 hello world。
先把环境和器件认知做扎实，这一周的目标不是做复杂电路，而是建立“能继续往下学”的底座。

任务顺序

  • 先装软件，再检查工程文件能否创建和保存。
  • 再做器件认知，最好把实物和图纸对应起来。
  • 随后完成 C 语言最小程序和编译运行。
  • 最后下单采购：面包板、阻容包、LED 包、三极管、杜邦线、后续可能用到的 IC、STM32F103C8T6 开发板。

提交建议

  • 环境安装截图
  • 器件整理照片
  • 学习记录或简短文档

物料准备

  • 采购：面包板、阻容包(插件与0603贴片件)、LED 包、三极管(S8050、S8550)、杜邦线、常用 IC 收纳盒、STM32F103C8T6 开发板(功能由预算决定)。
  • 准备：个人电脑、稳定网络、嘉立创 EDA、Multisim、C 语言开发环境、电子笔记本、器件收纳盒。

第 2 周 · 9月8日 - 9月14日 · 视频第二讲等

典型电路、仿真与 PCB

这一周要从“看懂器件”走向“把器件拼成能工作的电路”。

重点：先仿真，再上板

本周任务

  • 用面包板点亮 LED，尝试用电位器控制亮度。
  • 在上一步基础上加入三极管控制，重点理解饱和区工作方式。
  • 学习运算放大器原理和电路分析方法，仿真验证常见运放电路。
  • 使用仿真软件完成电赛校内赛第一题两问。
  • 把上述电路转到嘉立创 EDA 绘制 PCB，并提交打样。
  • C 语言继续推进到变量、函数、基本运算符。
这一周最容易出错的地方不是“画不出来”，而是“原理没吃透就直接抄图”。先仿真，再画板。

任务顺序

  • 先完成 LED 电路和亮度调节。
  • 再做三极管控制，记录开关状态和电流变化。
  • 随后做运放电路仿真，必要时用面包板验证。
  • 最后整理 PCB 截图和原理解释报告。

提交建议

  • 仿真文件
  • 面包板电路演示视频
  • PCB 截图
  • 原理解释报告

物料准备

  • 采购：运放芯片(如 LM324 、LM358)、蓝白电位器、打样所需基础元件。
  • 准备：Multisim 元件库、嘉立创 EDA 账号、万用表、手机或相机。

视频入口

  • 第二讲：基本电子元器件介绍

第 3 周 · 9月15日 - 9月21日 · 视频第五讲

电源链路与系统设计

这一周的核心是“系统思维”：输入、充电、转换、保护、接口一起看。

重点：不允许边冲边放

本周任务

  • 输入一节可插拔标称 3.7V 锂电池，容量不低于 500mAh。
  • 可由 USB 5V 充电，考虑焊接难度可用两脚 microUSB。
  • 设计时不允许支持边冲边放，充电时输出口不得带有电压。
  • 实现三路输出：3.7V boost 到 5V，5V buck 到 3.3V，3.3V 通过 LDO 到 2.5V。
  • 接口可自选，但链路关系要清楚。
  • C 语言推进到结构体、联合体，并开始接触堆栈概念。
这周的重点是电源系统约束，不是单纯“堆模块”。先画框图，再拆芯片和保护条件。

任务顺序

  • 先画出完整电源树和充电逻辑。
  • 再决定芯片与接口。
  • 最后输出 PCB 截图和原理说明。

提交建议

  • PCB 截图
  • 原理解释报告

物料准备

  • 采购：3.7V 可插拔锂电池（>=500mAh）、microUSB 两脚座或 USB 5V 输入口、充电芯片或充电模块、升压芯片、降压芯片、LDO、电感、电容、电阻、接口座、排针。
  • 准备：电源路径框图、各芯片数据手册、万用表、可调电源（若有）、细致的原理分析笔记。

第 4 周 · 9月22日 - 9月28日 · 视频第三、第四讲

STM32、焊接与验证

这一周进入“从原理到实物”的关键阶段。

重点：环境 + 焊接 + 验证

本周任务

  • 初步了解 STM32，搭建基于 HAL 库的开发环境。
  • 使用 STM32 点亮一颗 LED，进度快者可以尝试流水灯。
  • 了解 UART、IIC、SPI、CAN 等常见有线通信协议。
  • 学习焊接基础和安全规范。
  • 把第二、三周打样的 PCB 焊接并验证。
  • C 语言推进到指针，深入理解数组、字符串、结构体与指针的关系。
这一周不要只看视频。焊接、接线、下载程序、串口打印，至少要跑通一个完整演示链路。

任务顺序

  • 先配置 STM32 开发环境。
  • 再完成 LED 点亮与基础外设尝试。
  • 然后看焊接规范，焊接并调试前几周的板子。
  • 最后整理实物图片、视频和 C 语言学习记录。

提交建议

  • 演示视频
  • 学习文档
  • C 语言学习记录
  • PCB 焊接成品图片

物料准备

  • 采购：STM32F103C8T6 开发板、USB 数据线、杜邦线、焊锡丝、助焊剂、吸锡带、排针、热缩管。
  • 准备：电烙铁或焊台、焊接支架、万用表、ST-Link 或串口下载器、STM32CubeMX、VS Code、前几周打样板和元件包。

第 5 周 · 9月29日 - 10月5日 · 视频第六讲

最小系统板与外设入门

从“会用开发板”进到“会做开发板”。

重点：最小系统板

本周任务

  • 了解 STM32 最小系统板。
  • 在嘉立创 EDA 绘制 STM32F103C8T6 最小系统板，并提交打样。
  • 学习 GPIO、时钟树、定时器等知识，尝试相关实验。
这周要开始从“库函数演示”转向“板级设计能力”。最小系统板是很好的能力检验点。

任务顺序

  • 先理解最小系统板组成。
  • 再画图、检查供电和复位/下载相关电路。
  • 之后补 GPIO 和时钟树知识。
  • 最后做实验并输出说明。

提交建议

  • 演示视频
  • PCB 截图
  • 原理解释报告

物料准备

  • 采购：STM32F103C8T6 芯片、最小系统板空板或打样板、8MHz 晶振及配套电容、复位按钮、BOOT 跳帽、去耦电容、稳压器、SWD 接口、排针座、指示灯、限流电阻、SEGGER J-Link。
  • 准备：嘉立创 EDA 原理图库与封装库、下载器和编程线、万用表、基本调试记录模板。

第 6 周 · 10月6日 - 10月12日 · 收束与综合

中断、ADC 与通信整合

这一周是把单项知识拉回工程场景，形成完整演示。

重点：综合通信

本周任务

  • 学习 STM32 开发中的中断、ADC 等知识。
  • 巩固有线通信协议。
  • 尝试实现单片机与下位机芯片，以及与电脑通信。
这一周的重点是把“外设能用”变成“系统能通信、能采样、能解释”。

任务顺序

  • 先做中断和 ADC 的基础实验。
  • 再接回前面学过的通信协议。
  • 最后完成通信演示和视频记录。

提交建议

  • STM32 演示视频

物料准备

  • 准备：串口调试助手、示波器或逻辑分析仪（有则更好）、前几周完成的板子、现成固件工程和测试记录。
